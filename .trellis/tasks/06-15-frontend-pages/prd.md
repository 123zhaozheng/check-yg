# 前端页面实现 PRD

## 概述

实现 Check-YG Web 审计系统的核心前端页面，基于 React Router + shadcn/ui + Tailwind CSS，采用暗色主题设计。

## 页面清单

### 1. 登录页 (`/login`)
- 暗色背景，居中卡片布局
- 用户名/密码输入框
- 登录按钮
- 忘记密码/邀请注册链接
- 版本信息展示

### 2. 布局框架 (`/` 根布局)
- 左侧导航栏（Dashboard, Tasks, Customers, Analytics, Templates, Prompts, Logs, Settings）
- 顶部搜索栏 + 通知 + 设置 + 用户头像
- 用户资料和主题切换入口

### 3. 仪表盘页 (`/dashboard`)
- 欢迎语 + 日期显示
- 统计卡片：总任务数、活跃任务、本月完成、总客户数、待处理
- 最近任务列表
- 审计进度概览
- 审计优先级列表

### 4. 任务页 (`/tasks`)
- 任务列表表格（任务编号、客户名称、状态、创建时间、优先级等）
- 筛选器：状态、优先级、日期范围
- 搜索框
- 新建任务按钮
- 分页
- 底部统计摘要

### 5. 客户页 (`/customers`)
- 客户名单卡片网格
- 筛选器：重点关注、黑名单、仅显示活跃
- 导入名单 / 新建名单按钮
- 每个卡片显示：名称、标签、客户总数、进度条、更新人员/时间
- 创建新名单入口
- 分页

### 6. 设置页 (`/settings`)
- 左侧分类：基础、AI、安全
- MinerU 配置：解析模式、最大并发数、API 端点
- LLM 大语言模型配置：Base URL、模型名称、API Key
- 测试连接 / 保存设置按钮
- 配置助手侧边栏

### 7. 分析页 (`/analytics`)
- 全局数据概览：总文档数、总记录数、总金额、总客户数
- 每日处理趋势图（最近 30 天）
- 客户参考 Top 10 列表
- 处理类型分布饼图
- 平均处理时间折线图
- AI 洞察列表

## 技术栈

- **框架**: React Router v7
- **UI 组件**: shadcn/ui (已安装)
- **样式**: Tailwind CSS + 暗色主题
- **状态管理**: Zustand (auth) + React Query (数据)
- **API**: 已封装 `~/lib/api.ts`
- **WebSocket**: 已封装 `~/lib/websocket.ts`

## 设计系统

参考 `stitch_audit_system_web_ui_spec/audit_precision_interface/DESIGN.md` 中的颜色规范：
- 背景色: `#131313`
- 主色: `#ffffff`
- 次要色: `#bec6e0`
- 强调色: `#10B981` (正), `#EF4444` (负), `#F59E0B` (警告)

## 路由结构

```
/login          - 登录页
/               - 根布局（需认证）
  /dashboard    - 仪表盘
```
